
**grimm minimal subway clone**

black / white / concrete. endless.

### PLAY
**Live:** https://j4s3ph4.github.io/recon-runner/

### CONTROLS
- A / D or ← / → : switch lanes
- W / SPACE / swipe up : jump
- S / swipe down : roll under

### STACK
- single file `index.html` - 8KB
- canvas, no deps, no images
- works on mobile + desktop
- highscore saved locally

### HOST
1. fork this repo
2. settings -> pages -> deploy from main
3. done

a minimal recon TUI presents
